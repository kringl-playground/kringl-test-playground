# Kringl test playground

A tiny public repo used by the Kringl team to run real end-to-end tests of the
connectors (Slack, Monday) on the test workspace. Nothing here is a product.

- `index.html`: a one-page site with a greeting.
- `greeting.js`: the text of the greeting; connector tests usually ask to change it.
- The greeting was changed in the merge desk demo on 27.09.2026 (chat #1020).
